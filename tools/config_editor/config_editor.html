Scenario configuration

oo_v1 · writes a delta into config/personal/
How this file is used. You are editing a delta: only the knobs you change are written, and everything else is inherited from the base through _extends, exactly like the shipped ladder rungs. Save into config/personal/, then run it by name alone: run_oo_v1('myRun.json', 3600).

Switching an effect on or off is one checkbox, the row tagged master toggle. It drives that effect's internal truth and model pair for you, so set the master and leave the pair alone. Writing a pair member directly makes your file own it and stops the master from driving it, which is how six shipped ladder rungs once disabled nothing at all.

Before you run it, check it in MATLAB with checkPersonalConfig('myRun.json'). This page knows the base file's own keys, but the realism grade and the atmosphere profile derive further values at resolve time, and only MATLAB can tell you what a knob actually resolves to and whether anything you set was overridden.

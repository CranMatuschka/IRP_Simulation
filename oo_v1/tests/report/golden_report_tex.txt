\section{Scenario Summary}
This report documents a reverse-GNSS simulation run using the oo\_v1 MATLAB simulator. The ground segment transmits reverse-GNSS code, Doppler, and carrier observables to a GEO space receiver when enabled. The EKF estimates spacecraft position, velocity, attitude, and receiver clock states from the available observables. The run length is 0.08 hours (300 s) with 1.0 s sampling and 5 ground towers, 4 receiver phase centre(s). Code mode: \texttt{singleFrequency}. Carrier mode: \texttt{ekfFloat}. Tower clock mode: \texttt{truthHistoryProductNoisy}. Stage        : 85 -- Formal Synthetic Validation Campaign and Statistical Consistency Audit

\subsection{Receiver Clock Architecture Interpretation}
Receiver clock bias $b_{rx}$ has a \textbf{positive} sign (adds to pseudorange). Tower transmitter clock bias $b_{twr}$ has a \textbf{negative} sign (subtracts from pseudorange). Troposphere delay $T$ is \textbf{positive} for both code and carrier. Ionosphere delay $I_f$ is \textbf{positive} for code (group delay) and \textbf{negative} for carrier (phase advance). Carrier ambiguity $B_\phi$ is a float value in metres (raw L1, no integer fixing).

\textbf{Clock architecture:} \texttt{spacecraftReceiverClockOnly}. \textbf{Clock gauge:} \texttt{externalTowerCorrections}.

Tower clock states are not included in the EKF. The EKF estimates the spacecraft receiver clock only. One-way pseudorange is gauge-ambiguous: $b_{rx}$ and $b_{twr}$ cannot be separated without an external datum or gauge constraint; here the gauge is resolved by external tower clock corrections.

\subsection{Scenario Geometry and Receiver Architecture}
Truth pseudorange: $P = \|\mathbf{r}_{sc} + \mathbf{C}_{BI}\mathbf{l}_{a,B} - \mathbf{r}_{twr}\|+ b_{rx}^{true} - b_{twr}^{true} + d_{truth} + \nu$. Estimator prediction: $\hat{P} = \|\hat{\mathbf{r}}_{sc} + \hat{\mathbf{C}}_{BI}\mathbf{l}_{a,B} - \mathbf{r}_{twr}\| + \hat{b}_{rx} + d_{model}$. Range geometry uses ECEF positions at the receiver epoch. Optional light-time and Sagnac corrections are applied when enabled.

\subsection{EKF State Vector}
The filter is an error-state EKF. The 14 base states are: position (3), velocity (3), attitude error (3), angular rate (3), receiver clock bias (1), receiver clock drift (1).
